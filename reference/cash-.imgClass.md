# Custom `$` operator for imgClass Allows access to the underlying data matrix via `img$matrix`

Custom `$` operator for imgClass Allows access to the underlying data
matrix via `img$matrix`

## Usage

``` r
# S3 method for class 'imgClass'
x$name
```

## Arguments

- x:

  An object of class 'imgClass'

- name:

  The name of the element to extract
