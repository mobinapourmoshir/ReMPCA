# Custom `$` operator for fdClass Allows access to the underlying data matrix via `fd$matrix`

Custom `$` operator for fdClass Allows access to the underlying data
matrix via `fd$matrix`

## Usage

``` r
# S3 method for class 'fdClass'
x$name
```

## Arguments

- x:

  An object of class 'fdClass'

- name:

  The name of the element to extract
