# Print Method for Image Data (imgClass)

Displays summary information about an imgClass object, including its
dimensions, smoothing/sparsity parameters (if any), and a preview of the
image data.

## Usage

``` r
# S3 method for class 'imgClass'
print(x, ...)
```

## Arguments

- x:

  An object of class `imgClass`.

- ...:

  Additional arguments (ignored).

## Value

The object `x` is returned invisibly.
