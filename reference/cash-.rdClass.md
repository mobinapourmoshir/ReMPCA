# Custom `$` operator for rdClass Allows access to the underlying data matrix via `rd$matrix`

Custom `$` operator for rdClass Allows access to the underlying data
matrix via `rd$matrix`

## Usage

``` r
# S3 method for class 'rdClass'
x$name
```

## Arguments

- x:

  An object of class 'rdClass'

- name:

  The name of the element to extract
